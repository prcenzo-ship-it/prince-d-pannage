Mise en ligne IONOS :
1. Décompresser le ZIP.
2. Envoyer le CONTENU du dossier prince-depannage-site dans le répertoire Web cible,
   de façon à avoir index.html directement à la racine du site.
3. Utiliser SFTP/SSH pour un hébergement Linux IONOS.
4. Activer le SSL du domaine et forcer HTTPS.
5. Tester les boutons d'appel sur mobile et ordinateur.
6. Vérifier les images et toutes les pages.
7. Renseigner le vrai nom de domaine dans les données structurées de index.html.

IMPORTANT AVANT PUBLICATION :
- Le numéro RCS, s'il est applicable, et le numéro de TVA intracommunautaire doivent être vérifiés/renseignés
  selon la situation administrative réelle.
- Le médiateur de la consommation effectivement désigné par l'entreprise doit être renseigné dans
  mentions-legales.html et cgv.html. Aucun médiateur n'a été inventé dans cette V2.
- Vérifier que la promesse 24h/24 et 7j/7 correspond à la disponibilité opérationnelle réelle.
- Vérifier que les prestations annoncées correspondent exactement aux prestations proposées.
- Vérifier le nom de domaine puis remplacer https://VOTRE-DOMAINE.FR dans le JSON-LD.
